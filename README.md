# Automatic Speech Recognition (ASR)

This repository contains the code I implemented during my internship at the Laboratoire d’Informatique de Grenoble (LIG).

Briefly, the project aims to classify different accents in the French language. My work focused on analyzing the performance of a state-of-the-art model, WhisperX, and implementing an algorithm, ROVER, to combine transcriptions from different models (WhisperX and FrWhisper from HuggingFace) in order to obtain more accurate results.

For privacy reasons, most of the data used during this internship cannot be published. However, one dataset is publicly available: https://cfpr.huma-num.fr/.  
This dataset must be placed in a folder named `cfpr_audio`.

With the authorization of my supervisor, I am sharing this repository. Below is the project structure and its description.---

### 🔊 `cfpr_audio.../`

Folders with this prefix contain audio files extracted from specific `.zip` archives.
For example:

| Folder | Source Archive |
|---|---|
| `cfpr_audio` | First audio files received for the project |
| `cfpr_audio_24_25` | `CFPR_2425.zip` |
| `cfpr_audio_2022a_2023` | `2022a_Transcriptions.zip` + `2023_Transcriptions.zip` |

---

### 📝 `merged_transcriptions.../` and `merged_transcriptions..._full/`

These folders contain merged transcriptions of the audio files. As with the `cfpr_audio.../` folders, the suffix indicates the source dataset.

- **Standard version** — contains only `words` (or `word_segments`)
- **`_full` version** — contains both `segments` and `word_segments`

---

### ⚙️ `output.../`

These folders contain transcriptions generated by **WhisperX** for different audio datasets. The suffix specifies the corresponding audio folder.

**Example:** `output_all_interviews_2024_2025` → generated from `cfpr_audio_all_interviews_2024_2025/`

---

### ✂️ `segmentation/`

Contains the following subfolders:

- **`audio.../`** — Audio files split according to the alignment produced by WhisperX
- **`transcriptions.../`** — Transcriptions of the split audio files generated by FrWhisper

---

### 💻 `src/`

Contains the main scripts developed during the internship (see [Pipeline](#pipeline) and [Other Functions](#other-functions) below).

---

### 📊 `data/`

Contains:
- Text files used to generate figures
- The `.zip` archives from which audio files originate

---

### 📈 `figures/`

Contains all generated figures.

## 🔄 Pipeline

The following steps describe the full pipeline to process a folder of audio files and obtain their transcriptions.

> ⚠️ For most scripts, check and properly set the **input and output paths** before running.

1. **`script_folder.py`**  
   Generate WhisperX transcriptions for all audio files in a folder.

2. **`segmentation.py`**  
   Split audio files into segments based on the timestamps provided by WhisperX.

3. **`script_FrWhisper.py`**  
   Generate transcriptions using the second model, FrWhisper.

4. **`merge_rover.py`**  
   Merge both transcriptions to create a combined output, using WhisperX as the base and injecting relevant words from FrWhisper.

5. **`compute_WER.py`** *(optional)*  
   If reference (gold) transcriptions are available, compute the **Word Error Rate (WER)** to evaluate transcription quality.

6. **`compute_DER.py`** *(optional)*  
   If gold transcriptions are available, compute the **Diarization Error Rate (DER)** to evaluate speaker diarization.  
   > Note: DER is not computed for the merged transcription by default, as its diarization is close to WhisperX. It can be added if needed.

7. **`display.py`** and **`display_diarization.py`** *(optional)*  
   Generate visualizations summarizing transcription and diarization results.

## 🧰 Other Functions

The following utility scripts can be used independently depending on your needs.

| Script | Description |
|---|---|
| `change_to_json.py` | Converts a `.trs` file into a JSON file |
| `change_to_text.py` | Converts a JSON transcription file into a readable dialogue between speakers |
| `clean_json.py` | Cleans a JSON file by removing special characters and standardizing its format |
| `clean_new_audios.py` | Cleans and standardizes a set of audio files |
| `involve_whisperx.py` | Enriches a WhisperX transcription by injecting words added during the merge step |
| `maxduration.py` | Computes the mean and maximum duration of a set of audio files |
| `assign_transcriptions.py` | Assign transcription JSON and TRS files to their corresponding subfolder.|
| `script_whisperx_one_speaker.py` | Generate WhisperX transcriptions for all audio files in a folder.But the audio files were segmented to contain only one speaker |
